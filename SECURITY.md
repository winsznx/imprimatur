# Security

Imprimatur is a security tool, so reports about it are welcome and taken seriously.

Report a vulnerability privately through GitHub's "Report a vulnerability" on this repository. Please
include the surface (core, CLI, extension, Checkpoint), steps to reproduce, and what an attacker gains.

Known limits are documented in the README's Limitations section and the threat model in
`arkiv/schema.md`. A report that defeats one of the covered threats there is the most useful kind.

All keys in this repository's demo are testnet keys for the Tiramisu network. No mainnet funds are involved.
