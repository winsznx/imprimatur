# Contributing

```sh
pnpm install
pnpm typecheck
pnpm test
pnpm build
```

Layout:

| Path | What |
|---|---|
| `packages/core` | hashing, the Arkiv query, `decide()`, `describe()`; shared by every surface |
| `packages/cli` | `imprimatur` CLI and the watcher |
| `apps/extension` | Chrome MV3 extension |
| `apps/checkpoint` | the static verification page |
| `apps/demo` | Treasury Demo and the simulated bucket swap |
| `arkiv/` | data contract, friction report, probe, on-chain evidence |
| `proof/` | real-dapp scan, tamper campaign, revocation latency |
| `examples/` | a second client written from the data contract alone |

Rules that keep the verdict honest:

- Trust comes only from `$creator` terms. Never let a writable attribute decide a verdict.
- Every user-facing sentence is generated by `describe()` from the same `Decision` the gate acts on.
- Anything read from Arkiv is untrusted: build DOM with text nodes only.
- Tests sit in `packages/core/test` and use `#given / #when / #then`.
