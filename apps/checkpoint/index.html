Connecting to Tiramisu

Don't sign for code nobody signed.

This page fetches each site's scripts from outside the site, hashes them, and checks them against the release its team signed onto Arkiv. It never runs the code it checks. The verdict comes from who created the release on chain, not from anything the release says about itself.

The file that drained Bybit

app.safe.global served _app-52c9031bfa03da47.js to every visitor. On Feb 19 2025 attackers replaced it in Safe's S3 bucket. It behaved normally for everyone except two Safe addresses, one of them Bybit's cold wallet. Both versions are in the Wayback Machine.

  1. Feb 13, 11:35 v1.50.3 deployed
  2. Feb 19, 15:29 file replaced, same name
  3. Feb 21, 14:13 signers approve, $1.5B leaves
  4. Feb 21, 14:15 original file back, 117 s later

If you ship a frontend

            
One step after your build. The release key lives in your repository's secrets, not on the web host.

            
- uses: winsznx/imprimatur@main
  env:
    IMPRIMATUR_PK: ${{ secrets.RELEASE_KEY }}
  with:
    origin: app.example.org
    build-dir: dist
